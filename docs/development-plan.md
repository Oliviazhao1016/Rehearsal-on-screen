# MVP 开发计划

依据：[PRD.md](./PRD.md)。开发按可运行的用户旅程推进，每阶段完成后可独立检查。

| 阶段 | 交付内容 | 验收方式 | 状态 |
| --- | --- | --- | --- |
| 1. 应用骨架 | React + TypeScript、素材接入、开场动画、剧目列表、新建剧目与舞台选择 | 可从空列表创建剧目并进入排练页 | 已完成 |
| 2. 排练编辑 | 单 Scene、演员与道具、舞台网格与标记、Position 创建／复制／排序／删除、自动保存与撤销 | 可以编排至少两个完整 Position，重新打开仍存在 | 核心已完成 |
| 3. 动线与播放 | Transition 走位时间、对象 Movement 时间与节点式动线、Next／空格键、预演播放控制 | 对象按预定直线／曲线和时间移动；再次 Next 或空格直接到位 | 核心已完成 |
| 4. 音乐与收尾 | 多音乐上传、拖动吸附与防重叠、播放同步、错误与空态、键盘和响应式检查 | 音乐与 Position 并轨，完成端到端排演流程 | 开发中 |

实现选择：本地单机网页应用，以浏览器本地存储保存剧目数据。音乐文件本期保存在当前浏览器中；跨设备协作和导出不属于 MVP。先将 PRD 中尚未敲定的交互按一致、可逆的规则实现，再依据实际使用反馈调整。

当前已具备：左侧演员／道具拖入舞台、演员多选与同步移动、双击改名与快速删除、可见性眼睛按钮、拖出舞台下场反馈、首个站位预设、复制与拖拽排序、默认动线与可混用直线／折点／曲线节点的编辑、站位时间点与 Transition 走位时间拖拽、有效对象 Movement 时间条拖拽／缩放及精确输入、Next／空格推进、自动预演及固定进度条、三面板折叠及桌面端可拖动分隔线、真实宽深比舞台及左右标尺坐标、隐藏原生滚动条与横向浏览箭头、30 秒静默保存反馈、撤销／重做、多音乐上传与时间轴拖动、Stage Mark 添加、网格与 Stage Mark 独立显隐、每 0.16 秒自动播放的完整逐帧开场、剧场背景的票夹式剧目入口、Art Deco 工作台框线与素材图标，以及本地 Oswald／Limelight 和仓耳渔阳体 W02／W05 字体。

下一轮优先补齐：

1. 补足 Movement 拖拽的边界提示，并用真实排演片段检验默认时长是否合适。
2. 让自定义 Stage Mark 可直接编辑位置和线形；让道具在画布上直接缩放、旋转。
3. 补齐音乐在多个片段间拖动时的吸附提示、替换后的播放同步，以及更多异常操作反馈。
4. 用实际排演片段试用首个 Position 的侧台布局、演员离场和再次入场的转换规则。
