# MVP 功能与界面走查（2026-09-23）

本记录供审核下一轮修复范围。以 [PRD](./PRD.md) 为验收基线；浏览器走查覆盖桌面 1440×900、1100×900、开场页 910×742，以及 800×900、390×844 的窄窗口。自动流程覆盖开场、建剧目、场景改名、演员拖拽及多选、站位排序、动线、Next、音乐上传、保存与重新打开。

## 本轮已修复并验证

- 票根顶部原有英文说明已恢复，移至装饰线下；名称、预览及操作区不再压住票面花纹。My Play 页无原生纵向滚动条，标题、说明与细分割线在 1100px 窗口可见。
- 票夹与票根已按素材原始 2:3 长宽比展示。编辑动线时切换「选择」不会退出编辑态；工具栏在窄宽度换行，完成编辑按钮不再被裁切。
- Stage Canvas 左右加入暗红色「下场」区；仅对象拖入侧区后下场，拖出画布不改变在场状态。Transition 只要任一端在场即显示并可编辑该对象动线，进出场动线连接对应侧台端点。
- 预设与自定义 Stage Mark 现可在画布右上解锁后选中、拖拽；右侧信息栏可编辑标记参数，左侧独立分组支持添加、隐藏、删除和收起。舞台参数弹窗不再包含 Stage Mark 编辑。
- 开场页脚更新为 `Created by SiriZhao, a crazy musical fan.`，910×742 窗口内完整显示。
- 演员拖动以按下时的原始位置计算位移，多选组保持相对间距；逐步拖动坐标不回跳。
- Next 按钮固定宽度，切换为「直接到位」后位置不抖动。Scene 名称可直接编辑。
- 工作台以细金线、双线和小菱形绘制直角 Art Deco 框线；演员默认酒红标记，可选五组复古 SVG 颜色。字体及原有四个核心色不变。
- 短音乐片段的重命名、替换、删除改放在可展开操作菜单，不再挤进片段内；同次选择两首音乐时依次排列，避免重叠。
- 当前开场素材目录改变后，动画会读取根目录现有编号帧及最终态，保持每帧 0.16 秒；入口不会因旧子目录消失而空白。
